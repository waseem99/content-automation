# Analyze social references

1. Require an owned, permitted, rights-holder, or lawful public internal-research declaration.
2. Run `refintel doctor`, `refintel capabilities`, and `refintel profiles` before the first batch.
3. Classify profile/page discovery separately from direct-media acquisition. Read
   `references/platform-matrix.md` before promising support.
4. Use `refintel run-reference` for one input and `refintel run-portfolio` for typed batches.
5. Select `cpu` by default, `gpu` only with local CUDA and Ollama, or `low-memory` as a disclosed
   fallback. Keep all media processing local.
6. Preserve normalized provenance, hashes, rights, measured evidence, extracted evidence, labeled
   model observations, failures, and limitations. Never persist credentials or absolute paths.
7. Produce temporal/carousel evidence, a fingerprint, originality-safe brief, and sanitized
   portfolio sync packet. Never copy scripts, shots, artwork, characters, branding, voices, music,
   or source assets.
8. Require explicit human rights and originality approval before linking research to an idea.
   Never generate, render, deploy, or publish automatically.

Use `references/evidence-contract.md` for evidence labels and required outputs. Use
`references/platform-matrix.md` for route limitations. Use `references/operator-runbook.md` for
commands, profiles, failure recovery, and acceptance.
