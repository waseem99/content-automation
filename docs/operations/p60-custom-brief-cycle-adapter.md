# P60 Custom Brief Review Cycle Adapter

Part of #651. Closes #652–#657 after merge.

## What this builds

P60 bridges a single Creator Studio brief into the local review cycle.

P59 lets a human draft and export a single brief JSON. P58 expects a demo brief library plus a matching feedback template. P60 creates those two inputs automatically.

## Local command

```bash
python -m src.p60_custom_brief_cycle_adapter \
  outputs/creator-studio/sample_brief.json \
  --output-root outputs/custom-brief-cycle \
  --overwrite
```

## Outputs

At the selected output root:

- `custom_brief_library.json` — one-item P55/P58-compatible library
- `custom_feedback_template.json` — matching feedback template using the generated demo slug
- `custom_cycle_manifest.json` — local artifact map and next steps
- `custom_cycle_readme.md` — operator instructions and P58 command

## Run the custom review cycle

After generating adapter files, run the command printed in `custom_cycle_readme.md`, for example:

```bash
python -m src.p58_review_cycle_runner \
  --demo-briefs outputs/custom-brief-cycle/custom_brief_library.json \
  --feedback outputs/custom-brief-cycle/custom_feedback_template.json \
  --output-root outputs/custom-review-cycle \
  --overwrite
```

Then open:

```text
outputs/custom-review-cycle/review_cycle_index.html
```

## Review process

1. Create or export a brief from P59 Creator Studio.
2. Run P60 to convert it into review-cycle inputs.
3. Run P58 using the generated library and feedback template.
4. Open the review cycle index.
5. Replace placeholder feedback with real human review notes.
6. Re-run the review cycle if needed.

## Important note

The feedback template generated by P60 contains placeholder review content. This is useful for smoke testing the full loop, but it must be replaced with real reviewer notes before production decisions.

## Deployment position

P60 is local-only. It does not deploy a hosted app, start a server, render video, download assets, upload, publish, call external services, or approve content for production automatically.
