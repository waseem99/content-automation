# P31 Step 02

Part of #419. Closes #421 after the batch PR merges.

## Goal

Define a weekly channel performance brief that summarizes content performance, learning, and operator interpretation without requiring a dashboard.

## Required sections

- `reporting_period`
- `executive_summary`
- `channel_health`
- `top_performers`
- `weak_performers`
- `audience_signals`
- `learning_summary`
- `recommended_focus_next_week`
- `review_required_items`

## Operator use

The brief should help an operator understand what performed, what underperformed, what should be repeated, and what requires review.

## Safety boundary

This is not an automated analytics dashboard and it is not automatically delivered.
