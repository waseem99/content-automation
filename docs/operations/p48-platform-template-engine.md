# P48 Platform-Specific Creative Template Engine

Part of #555. Closes #556–#561 after merge.

## What this builds

P48 makes the local video production output platform-native instead of generic.

## Target templates

- YouTube Shorts
- Instagram Reels
- TikTok
- YouTube longform
- Carousel/newsletter reuse

## Output

Each platform template includes:

- platform-native title
- adapted hook
- adapted CTA
- hook style
- pacing rules
- caption style
- scene count guidance
- metadata guidance
- storyboard adaptation notes
- export notes
- risk/compliance notes

## Deployment position

No trend scraping, platform API calls, rendering, upload, publishing, or performance guarantees.
